# Wiki_maintance_tools
A collection of several python run semi-automated tools for doing repetitive maintenance tasks on Wikipedia.
## Disambig delinker - Currently in progress
This tool is designed to help retargeting links from disambiguation pages, by going through disambiguation pages with links directed too it and providing a method of easily replacing the link.
## Short_desc
This tool is designed to help add short descriptions to pages without them by giving an easy method to find and add short descriptions.
